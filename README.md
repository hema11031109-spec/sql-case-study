This project focuses on analyzing student course enrollment details and payment information using SQL. The main objective is to understand student enrollment patterns, course preferences, and payment status.

🎯 Objectives
Analyze total student enrollments.
Identify popular courses.
Track student payment details.
Find pending and completed payments.
Analyze course-wise revenue.
Identify students with outstanding payments.

🛠️ Tools & Technologies
SQL
PostgreSQL
pgAdmin

📊 SQL Concepts Used
SELECT & WHERE
GROUP BY & ORDER BY
Aggregate Functions
JOINS
Subqueries
CASE Statements
Window Functions

📈 Key Analysis
Total number of enrolled students.
Course-wise enrollment count.
Total revenue generated.
Paid vs pending payments.
Student-wise payment analysis.
💡 Conclusion
This project helped me improve my SQL skills and understand how to analyze student enrollment and payment data to generate meaningful business insights.
